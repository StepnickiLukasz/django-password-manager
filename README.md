# Django Password Manager

Reusable Django application for managing user passwords, password history, password expiration and password resets.

The application helps enforce password reuse policies, expire user passwords after a configurable period and provide a mechanism for resetting a user's password and sending a temporary password by email.

## Features

* Password history management
* Prevents users from reusing previously used passwords
* Configurable password history period
* Password expiration after a configurable number of days
* Ability to deactivate a user's password and force them to set a new one
* Password reset action that:

  * generates a temporary password
  * sets it for the user
  * sends the temporary password to the user's email address
* Configurable temporary password length
* Configurable application information used in email messages
* Support for custom email headers

## Requirements

* Python 3.11+
* Django 5.2+

## Installation

Install the package using pip:

```bash
pip install django-password-manager
```

Then add the application to your Django settings:

```python
INSTALLED_APPS = [
    # ...
    "django_password_manager",
]
```

Add the password management middleware:

```python
MIDDLEWARE = [
    # ...
    "django_password_manager.middleware.PasswordHistoryManagerMiddleware",
]
```

Add the password history validator to `AUTH_PASSWORD_VALIDATORS`:

```python
AUTH_PASSWORD_VALIDATORS = [
    # ...
    {
        "NAME": "django_password_manager.password_validators.PasswordHistoryValidator",
        "OPTIONS": {
            "history_size_days_before": 31,
        },
    },
]
```

Finally, run the migrations:

```bash
python manage.py migrate
```

## Configuration

Django Password Manager can be configured through Django's `settings.py`.

### Password history

```python
PASSWORD_HISTORY_DAYS_LIMIT = 31
```

Defines how many days password history should be retained.

The password history validator uses this value to determine which previously used passwords should be considered when checking password reuse.

### Password expiration

```python
PASSWORD_DEFAULT_DAYS_TO_EXPIRE = 30
```

Defines the default number of days after which a password expires.

Set it to `None` if passwords should never expire:

```python
PASSWORD_DEFAULT_DAYS_TO_EXPIRE = None
```

### Temporary password length

```python
GENERATE_START_PASSWORD_LENGTH = 12
```

Defines the length of automatically generated temporary passwords.

### Application name

```python
APPLICATION_NAME = "App name"
```

The name of the application. Used in email messages sent by the password manager.

### Application URL

```python
APPLICATION_URL = "https://example.com"
```

The URL of the application. Used in email messages sent by the password manager.

### Support email

```python
SUPPORT_EMAIL = "support@example.com"
```

Support email address used in email messages generated by the application.

### Email subject

```python
EMAIL_SUBJECT = "Twoje hasło tymczasowe"
```

Subject of the email containing a generated temporary password.

### Sender email

```python
EMAIL_FROM = "from@example.com"
```

Email address used as the sender of password-related emails.

### Email headers

```python
EMAIL_HEADERS = {
    "List-Unsubscribe": "<mailto:unsub@example.com>",
}
```

Additional headers that should be added to emails sent by the application.

## Example configuration

A complete example configuration may look like this:

```python
# Django Password Manager settings

PASSWORD_HISTORY_DAYS_LIMIT = 31

# Number of days after which the password expires.
# Set to None to disable password expiration.

EMAIL_FROM = "from@example.com"
EMAIL_HEADERS = {
    "List-Unsubscribe": "<mailto:unsub@example.com>",

```

## Password history validation

The password history validator prevents users from changing their password to one that has already been used within the configured password history period.

Add the validator to `AUTH_PASSWORD_VALIDATORS`:

```python
AUTH_PASSWORD_VALIDATORS = [
    {
        "NAME": "django_password_manager.password_validators.PasswordHistoryValidator",
        "OPTIONS": {
            "history_size_days_before": 31,
        },
    },
]
```

The `history_size_days_before` option defines how far back the validator should look when checking previously used passwords.


## Password expiration

Passwords can be configured to expire automatically after a specified period.

```python
PASSWORD_DEFAULT_DAYS_TO_EXPIRE = 30
```

means that a password is considered expired after 30 days.

When a password becomes inactive or expires, the application can require the user to provide a new password.

To disable password expiration set value as None.

## Password deactivation

Django Password Manager provides the ability to deactivate a user's current password.

When a password is deactivated, the user is required to set a new password instead of continuing to use the inactive one.

This can be useful for:

* administrative password invalidation
* security incidents
* forced password changes
* password expiration policies
* account recovery procedures

## Password reset

The application provides an action for resetting a user's password.

The reset operation:

1. Generates a new temporary password.
2. Assigns the temporary password to the user.
3. Invalidates the previous password.
4. Sends the temporary password to the user's email address.

The generated password length can be configured using:

```python
GENERATE_START_PASSWORD_LENGTH = 12
```

The email is configured using:

```python
APPLICATION_NAME = "App name"
APPLICATION_URL = "https://example.com"
SUPPORT_EMAIL = "support@example.com"
EMAIL_SUBJECT = "Twoje hasło tymczasowe"
EMAIL_FROM = "from@example.com"
EMAIL_HEADERS = {
    "List-Unsubscribe": "<mailto:unsub@example.com>",
}
```

## Middleware

The application provides the following middleware:

```python
django_password_manager.middleware.PasswordHistoryManagerMiddleware
```

Add it to the Django middleware configuration:

```python
MIDDLEWARE = [
    # ...
    "django_password_manager.middleware.PasswordHistoryManagerMiddleware",
]
```

The middleware is responsible for handling password-related state during the request lifecycle and enforcing password management behaviour provided by the application.

## Security

Django Password Manager does not store user passwords in plain text.

Passwords should always be handled using Django's password hashing mechanisms.

The password history functionality compares newly provided passwords against stored password hashes rather than storing previous passwords as plain text.

Make sure your production application has a properly configured Django email backend and uses secure transport for email delivery where appropriate.
